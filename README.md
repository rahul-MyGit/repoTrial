# RepoTrial

RepoTrial is a practice platform for debugging unfamiliar codebases with an AI assistant. Instead of starting from a blank editor, you investigate an existing project, form a hypothesis about a failure, and work toward a tested fix.

## How it works

1. Choose a problem from a catalog of small, multi-file repositories.
2. Run the project, inspect the error, and record your initial diagnosis.
3. Explore the source code in a read-only workspace.
4. Ask the built-in AI assistant to investigate and propose changes.
5. Review its patch, run tests, and iterate until you can submit a solution.

RepoTrial is designed to help developers practice code comprehension, debugging, prompting, and checking AI-generated changes. The first release will focus on backend problems and will use Next.js, Go, and Postgres.

## Status

RepoTrial is in planning. The application is not yet available. This repository will contain the implementation as it is built.
